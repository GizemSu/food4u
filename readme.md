# Food4U – Online Food Ordering Website

## Project Overview

Food4U is a front-end web development project that 
simulates an online food ordering website. Users can 
browse the menu, search for food, view product details, 
and manage their shopping cart.

## Features

- Interactive food menu
- Food search by name or ingredients
- Expandable product details
- Shopping cart management
- Quantity controls
- Automatic price calculation
- Checkout functionality
- Contact form validation
- Live date and time display
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
